# Au quotidien — téléphone par câble USB

## Démarrer

1. Branchez le câble USB entre le téléphone et le PC.
2. Téléphone : activez **Modem USB** (*USB tethering*).
3. Téléphone : touchez **conductor** sur le widget Termux.
4. PC : lancez **conductor-usb** (raccourci du bureau ou du menu Démarrer, `app/tools/conductor-usb.bat` ;
   Linux : **conductor USB** dans le menu des applications, `app/tools/conductor-usb.sh`).
5. Tada ! conductor. s'ouvre, relié au téléphone : lancez un album.

## Arrêter

1. Fermez conductor. (l'onglet du navigateur).
2. Téléphone : touchez **conductor-stop** sur le widget Termux.
3. Débranchez le câble USB.
4. Tada !
